# Icon notices

The GitHub mark is GitHub artwork, not original Meridian artwork. It comes from
<https://github.githubassets.com/favicons/favicon.svg> and remains subject to
[GitHub's logo guidelines](https://github.com/logos).

Other glyphs in `meridian_ui/icon` are original Meridian artwork, covered by the
project's MIT licence. Style presets do not reshape or recolour the GitHub mark's
official silhouette.
